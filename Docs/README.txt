SKYHAVEN SURVIVAL — NATIVE ENGINE

Dvakrát klikni na Skyhaven Survival Native.exe.

Obsahuje:
- loading screen s průběhem načítání
- hlavní menu
- vlastní nativní 2D renderer pro mapu
- stromy, krystaly, ruiny a herní objekty
- hráče a pohyb po mapě
- inventář
- mapové menu
- HUD se zdravím, energií a surovinami

Ovládání:
W A S D = pohyb
I = inventář
M = mapa
ESC = zpět do hry
Kliknutí na NOVÁ VÝPRAVA = spuštění hry
