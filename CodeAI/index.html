    Profil a nastavení
    Šetrný režim zkrátí historii a obrázky a ve Windows sníží prioritu místního Qwen serveru, aby počítač mohl obsluhovat ostatní aplikace. Qwen může odpovídat až 15 minut; běh lze zastavit tlačítkem v chatu. Pokud server prioritu nepodporuje nebo PC stále nestíhá, sniž jeho CPU vlákna v LM Studio nebo použij menší model.

    Automatické aktualizace používají veřejné GitHub Releases.
    Připojení lokálního Qwen

    Chat potřebuje spuštěný modelový server. Nastavení je zdarma, ale Qwen se musí stáhnout do počítače a jeho rychlost závisí na paměti a grafické kartě.

    1. Nainstaluj LM Studio.
    2. V aplikaci vyhledej a stáhni model Qwen (např. menší Qwen 3 8B GGUF).
    3. Otevři Developer / Local Server, nastav port 1234 a spusť server.
    4. V Code AI ponech adresu http://127.0.0.1:1234 a klikni na ověření.
    Kontrola návrhu změn
    Změny se zapíší až po potvrzení. Existující soubory budou přepsány; návrh je omezen na složku otevřeného projektu.
